# स्वरामृत (SvarAmrit): ऐप डाउनलोड

दृष्टिबाधित पाठकों के लिए किताबें पढ़ने का ऐप, जो TalkBack के साथ पूरी तरह चलता है।

इस रिपोजिटरी में केवल ऐप की APK फ़ाइलें रहती हैं।

## नवीनतम संस्करण: 0.1.0 (परीक्षण संस्करण)

फ़ाइल: [`SvarAmrit-v0.1.0.apk`](SvarAmrit-v0.1.0.apk)

ज़रूरी: Android 7.0 या उससे नया फ़ोन।

### इस संस्करण में
- PDF (टेक्स्ट वाली) और DOCX किताबें जोड़कर पढ़ना।
- जहाँ छोड़ा था वहीं से पढ़ना शुरू होना।
- किसी भी पेज पर जाना, विषय-सूची, किताब में खोजना, बुकमार्क।
- अक्षर बड़े और छोटे करना।
- हिंदी और अंग्रेज़ी भाषा।
- नमूना किताब: "स्वरामृत: उपयोग मार्गदर्शिका", जो पहली बार ऐप खोलते ही जुड़ जाती है।

## इंस्टॉल करने का तरीका
1. ऊपर दी गई APK फ़ाइल के लिंक पर डबल-टैप करें।
2. GitHub के फ़ाइल पेज पर "Download raw file" (डाउनलोड) बटन पर डबल-टैप करें।
3. डाउनलोड पूरा होने पर फ़ाइल खोलें।
4. अगर फ़ोन "अज्ञात ऐप्स" (Unknown apps) की अनुमति माँगे, तो उस ब्राउज़र या फ़ाइल मैनेजर के लिए "इस स्रोत से अनुमति दें" चालू करें, फिर वापस आएँ।
5. "इंस्टॉल करें" पर डबल-टैप करें।
